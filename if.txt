  Else if lanc: FELULROL lefele, az elso igaz agon fut le, a tobbi kimarad.
  -> a sorrend szamit: a szukebb / specialisabb feltetel menjen ELOL.

  Feltetelek:
  intervallum [a;b]   :  x >= a && x <= b         nyilt (a;b): x > a && x < b
  intervallumon KIVUL :  x < a || x > b
  oszthato n-nel      :  x % n == 0
  paros / paratlan  :  x % 2 == 0  /  x % 2 != 0   (negativnal != 0, nem == 1)
  ket ertek egyike    :  x == 3 || x == 5            (NEM: x == 3 || 5)
  bool valtozo        :  if (van) ...    if (!van) ...
  Szoveg: == a tartalmat hasonlitja, de a kis/nagybetu KULONBOZIK:
    string v = "Igen ";
    if (v.Trim().ToLower() == "igen") Console.WriteLine("igen ag");
  Egymasba agyazas = &&:   if (a) { if (b) ... }   ==   if (a && b)

  Tobb ag egymas utan (kulon if-ek) NEM ugyanaz, mint else if: kulon if-nel
  mindegyik feltetel kiertekelodik, es tobb is lefuthat.
  Gyakori hibak:
  - if (x = 5)  <- ertekadas!  Helyes: if (x == 5)
  - if (x > 3);  <- ures utasitas a ; miatt
  - double == double egyenlosegvizsgalat: pontatlan lehet
  Tobbagu valasztas diszkret ertekekre: j switch
