PAROS OSSZEHASONLITAS (utkozes) + VELETLEN VALASZTAS          [ZH2 extra]
=============================================================================
Termek: nev, kategoria (string); ar (int); akcios (bool); datum (DateTime)

MINDEN PAR EGYSZER: j = i + 1-tol (igy nincs onmagaval, nincs duplan)
    List<Termek> lista = new List<Termek>();
    bool utkozes = false;
    for (int i = 0; i < lista.Count - 1; i++)
    {
        for (int j = i + 1; j < lista.Count; j++)
        {
            if (lista[i].datum == lista[j].datum)
            {
                Console.WriteLine($"{lista[i].nev} - {lista[j].nev}");
                utkozes = true;
            }
        }
    }
    if (!utkozes)
        Console.WriteLine("Nincs utkozes.");

  Csak ugyanaz a NAP (ido nem szamit):
  lista[i].datum.Date == lista[j].datum.Date
  Ket idoszak atfed:  kezd1 < veg2 && kezd2 < veg1
  Tobb feltetel:      ... && lista[i].kategoria == lista[j].kategoria

VELETLEN VALASZTAS EGY CSOPORTBOL
    List<Termek> lista = new List<Termek>();
    Random rnd = new Random();
    List<Termek> jeloltek = new List<Termek>();
    foreach (Termek x in lista)
        if (x.kategoria == "pekaru")
            jeloltek.Add(x);
    if (jeloltek.Count > 0)
    {
        Termek v = jeloltek[rnd.Next(jeloltek.Count)];   // 0..Count-1
        Console.WriteLine($"Valasztott: {v.nev}");
    }
    else
        Console.WriteLine("Nincs ilyen termek.");
