CSV BEOLVASAS  (StreamReader)                                       [ZH2]
=============================================================================
  using System.IO;   (datumhoz: using System.Globalization;)

  A beolvasas LEPESEI (a ciklust es az osszeallitast te ird meg):
  1) osztaly a CSV sor mezoire (a bool mezot a szovegbol szamold: == "I")
  2) List<osztaly> a peldanyoknak                  (j lista, j osztaly)
  3) StreamReader megnyitasa
  4) A FEJLEC eldobasa: egyetlen ReadLine() az elejen
  5) ciklus: amig nincs vege a fajlnak
  6) sor szetvagasa Split(';')
  7) mezonkent konvertalas: int.Parse, DateTime.ParseExact, == osszehasonl.
  8) uj objektum a mezokbol, hozzaadas a listahoz
  9) fajl lezarasa

  Szintaktikai reszletek:
    StreamReader sr = new StreamReader("adatok.csv");
    string fejlec = sr.ReadLine();         // az elso sor (fejlec)
    bool vege = sr.EndOfStream;            // igaz, ha nincs tobb sor
    string sor = sr.ReadLine();            // kovetkezo sor
    sr.Close();
  Az oran szereplo minta (egy szam / sor):
    List<int> l = new List<int>();
    StreamReader stream = new StreamReader("szamok.txt");
    while (!stream.EndOfStream)
        l.Add(int.Parse(stream.ReadLine()));
  Szetvagas es konvertalas (egy sor szovegen):
    string minta = "Alma;300;igen;2024.12.17";
    string[] t = minta.Split(';');          // t[0]="Alma", t[1]="300", ...
    string nev = t[0];
    int ar = int.Parse(t[1]);
    bool bio = t[2] == "igen";
    DateTime datum = DateTime.ParseExact(t[3], "yyyy.MM.dd",
                                         CultureInfo.InvariantCulture);
    string[] tagek = "zeller,gomba".Split(',');  // mezon belul is lehet lista
  Datum + ido ("2024.11.25 11:30"): "yyyy.MM.dd HH:mm" (HH!, j datetime)
  Valos mezo ponttal (3.5): double.Parse(s, CultureInfo.InvariantCulture)

  ELERESI UT: a relativ nev a FUTTATO mappahoz kepest ertendo (bin\Debug\...).
  - a fajlra: Properties -> Copy to Output Directory: "Copy if newer", VAGY
  - teljes ut: @"C:\temp\NEPTUN\adatok.csv"
  Ha FileNotFoundException: nincs ott a fajl, ahol keresi (j hibauzenet).
  Kodolas: UTF-8 az alap; a BOM-ot a StreamReader maga kezeli.
  Ures sor a fajl vegen: Split utan t.Length == 1 -> IndexOutOfRange; ezt
  kezeld, ha a futas ilyenkor elszall.
  Ellenorzes beolvasas utan: lista.Count egyezik a fajl sorszamaval (fejlec
  nelkul)? Irasd ki az elso es az utolso elemet is.
