            ... a tetel (osszegzes / max / mind-e / megszamolas) ...

         max/min tetel a CSOPORTATLAGOKON (kulon min valtozo + csoport index)

         csoportonkent mind = igaz; ha (NEM feltetel) mind = hamis;
         a csoport vegen: ha (mind) { db = db + 1 } / van = igaz

    Veletlen elem egy csoportbol: j = rnd.Next(meret); elem = t[cs*meret + j]
