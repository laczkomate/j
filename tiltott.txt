TILTOTT / VESZELYES  (a ZH-n automatikus elegtelen is lehet)
=============================================================================
MINDEN ZH-BAN
  x top-level statement (kotelezo: class Program + Main)
  x lambda ( => ) es LINQ: Where, Select, OrderBy, Any, All, First, Last,
    ToList, ToArray, Count(...)  -- using System.Linq; fel se vedd!
  x lambdas listametodusok: Find, FindAll, Exists, RemoveAll, Sort(x => ..)
  x internet, orai anyag, MI, kommunikacio

TOVABBA ZH1-BEN (es a levelezos dolgozat 1. feladataban)
  x List<T> (tomb alapu lista) -- csak tomb es ciklus
  x Sum()  Min()  Max()  Average()  Contains()  IndexOf()  First()  Last()
  ? Array.Sort / Array.Reverse / Array.IndexOf / string.Contains stb.:
    a kiiras csak peldakat sorol ("mint pl. ..."), minden algoritmus-jellegu
    beepitett metodus gyanus. Ha bizonytalan vagy: irj ciklust.

ZH2-BEN
  OK:  Add  Insert  Remove  RemoveAt  Clear  Sort()  Reverse()  Count
  ?    Contains: csak ha ciklussal is meg tudnad irni
  x    Min / Max / Sum / Average jellegu muveletek: CIKLUSSAL kell

MIT IRJ HELYETTE
  Sum()      -> osszegzes ciklus            (j osszegzes)
  Average()  -> osszeg / darab ciklussal    (j osszegzes)
  Max/Min    -> maximum-kivalasztas ciklus  (j maximum)
  Contains   -> eldontes (van-e) ciklus     (j kereses)
  IndexOf    -> linearis kereses indexszel  (j kereses)
  First/Last -> t[0]  /  t[t.Length - 1]    (lista: l[l.Count - 1])
  Where      -> kivalogatas ciklus          (j kivalogatas)
  OrderBy    -> Sort() (ZH2) vagy kezi rendezes (j rendezes)
  Distinct   -> egyedi ertekek ciklus       (j egyedi)
  Count()    -> megszamolas ciklus; a lista .Count TULAJDONSAG (zarojel
                nelkul) rendben van

TIPP: az IntelliSense felkinalja a tiltott metodusokat (pl. t.Max()): ne
fogadd el automatikusan - gyakorlasnal is kapcsold ki az IntelliCode-ot.
