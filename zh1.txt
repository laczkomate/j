ZH1 TERKEP        (3 feladat; tomb + ciklus; NINCS List<T>, Sum/Min/Max...)
=============================================================================
Minden eddigi ZH1 (2021/22 - 2025/26, pot is) ugyanezt a 3 tipust varialja:

1. SZELEKCIO - arkalkulacio tablazat / savok alapjan            [j arkalk]
   Itt jon elo:
   - if / else if / switch, string-osszehasonlitas (igen/nem, tipusnev)
   - ELLENORZOTT bekeres: intervallum, oszthatosag (pl. 50-nel), megengedett
     ertekek (pl. csak 2, 3 vagy 5; csak 6 vagy 15)
   - "megkezdett egyseg" (Math.Ceiling), szazalek, kerekites
   - Random-generalt adat (egesz, valos 1-2 tizedessel), majd ebbol szamitas
   - extra: veletlen modositas (pl. +-10%)
   Kartyak: arkalk beker if switch math random

2. CIKLUS - folyamatos bekeres kulcsszoig                        [j kulcsszo]
   - STOP / kovetkezo / vegeztem / "uj ..." kulcsszo
   - TOBB leallasi/valtasi feltetel: kapacitas (db, perc, Wh) VAGY kulcsszo
   - szamlalok, osszegzes, hanyadik egyseg, mennyi maradt
   - kiiras: hh:mm, vegosszeg, db
   - extra: kategoriak (nevek, ertekek) kulon tombokben
   Kartyak: kulcsszo ciklus kiir math tomb

3. TOMB + RANDOM - sorfolytonos adat egy tombben                [j csoport]
   - ellenorzott darabszam (pl. 20..50), tomb merete = csoportok * meret
   - Random feltoltes (egesz / 1-2 tizedes valos, hatarok!)
   - globalis: felteteles atlag, felteteles osszeg / kepletes ertek,
     szamlalas, eldontes (van-e olyan, tobb-e ... mint ...)
   - csoportonkent: atlag, min/max, kulonbseg, "van-e olyan csoport, ahol
     minden ..." / "hany csoport ..."
   - extra: veletlen elemek modositasa korlattal (pl. max 100, min 0)
   Kartyak: tomb random csoport osszegzes maximum kereses

KOTELEZO REPERTOAR ZH1-HEZ: j tetelek (osszegzes, megszamolas, atlag,
eldontes, kivalasztas, kereses, max/min, csoportonkenti feldolgozas).

KERETEK:      j forma      TILALMAK:  j tiltott      BEADAS ELOTT: j ellenorzo
EMLEKEZTETO:  - a kiiras a MINTA szerint (szoveg, tizedes, mertekegyseg)
              - ahol nem kerik az ellenorzest, ervenyes adat jon
              - extra csak az alap utan
              - minden reszfeladat utan futtass es probalj szelso esetet

GYAKORLO FORRAS: Feladatgyujtemeny 2., 4., 5. fejezet; ZH1 2021-2025;
                 POT 2022/23 (ez tilt First/Last/Min/Max/Sum/Average/
